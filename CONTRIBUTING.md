# Contributing

Thank you for helping build OpenStream.

1. Search existing issues and open/claim a bounded issue before material changes.
2. Branch from current `main`; use one issue per branch and PR.
3. Keep production authority in Rust unless a documented platform boundary requires otherwise.
4. Add deterministic success and failure-path tests.
5. Never add telemetry by default, secrets, proprietary assets, or undocumented permissions.
6. Add an ADR for public protocol, irreversible architecture, security boundary, dependency policy, or migration decisions.
7. Run the repository checks and include exact commands/results in the PR.
8. Sign off commits under the Developer Certificate of Origin: `git commit -s`.

Security vulnerabilities must be reported privately as described in `SECURITY.md`, not in public issues.
