# Code of Conduct

OpenStream adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference.

We are committed to a welcoming, harassment-free community regardless of background, identity, experience, ability, or viewpoint. Be respectful, focus criticism on work and evidence, protect private information, and accept maintainer moderation.

Unacceptable behavior includes harassment, threats, sexualized attention, discriminatory language, doxxing, sustained disruption, and retaliation. Maintainers may edit, remove, reject, temporarily restrict, or permanently ban participation when needed to protect the community.

Report conduct concerns privately to the repository owner through the verified GitHub profile. Security vulnerabilities use the separate process in `SECURITY.md`.
