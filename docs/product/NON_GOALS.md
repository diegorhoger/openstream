# Non-goals and scope defenses

OpenStream does not become:

- an OBS replacement, video encoder, capture suite, or full audio router;
- an unrestricted local or remote shell;
- a clone of proprietary plugin marketplaces or copyrighted assets;
- a cloud-required subscription gate for local controls;
- a generic workflow automation platform before the live-production loop is excellent;
- a hardware manufacturing program before software protocol conformance exists;
- an AI-dependent product that fails when a model or provider is unavailable;
- a telemetry-first growth product;
- a reason to put desktop secrets in a browser or Cloud database;
- a compatibility promise for every controller, plugin, or streaming service.

Breadth follows proof. OBS onboarding, safety, portability, and reliability are the initial wedge.
