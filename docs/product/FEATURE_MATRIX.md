# Feature matrix

| Capability | Community desktop | Creator Cloud | Team/Enterprise | Native mobile |
|---|---:|---:|---:|---:|
| Account required | No | Yes | Yes | No on LAN |
| Offline execution | Full | Full local fallback | Full local fallback | Cached LAN decks |
| Unlimited local decks/workflows | Yes | Yes | Yes | Yes on LAN |
| Desktop editor and surface | Yes | Yes | Yes | N/A |
| Direct browser-to-LAN surface | No | No | No | N/A |
| Web editor/dashboard | No | Yes | Yes | N/A |
| OBS discovery and live feedback | Yes | Yes | Yes | Uses paired Engine |
| Hotkey/app/URL/media/HTTP actions | Yes | Yes | Yes | Triggers configured actions |
| Restricted process execution | Deferred pending hardened adapter | Same local boundary | Policy may forbid | Cannot author remotely |
| Multi-actions/conditions/variables | Yes | Yes | Yes | Trigger/status first |
| Import/export/open schema | Yes | Yes | Yes | Through local/Cloud workspace |
| Public protocols/clients/test vectors | Yes | Yes | Yes | Yes |
| Plugin/connector SDK | M5 | M5 | Private registry policy | No mobile runtime initially |
| Encrypted sync/backups | No | Yes | Yes | Via Cloud when subscribed |
| Version history/restore | Local snapshots | 90 days | One year/custom | View/use selected version |
| Remote internet relay | No | Yes | Yes | Optional through Cloud |
| Direct secure LAN control | No | No | No | Free and accountless |
| Shared workspaces/roles | No | No | Yes | Use assigned decks |
| Approvals/audit/fleet rollout | No | Personal history | Yes | Operator surface |
| Telemetry | Off by default | Opt-in product analytics | Admin policy + consent | Opt-in diagnostics |

The Community edition is not a trial. The hosted Cloud implementation is private; interoperability contracts and clients remain public.
